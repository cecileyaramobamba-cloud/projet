🗄️ Les jointures SQL

Exemple de cours donné par un tuteur EduSen en MySQL

🎯 Objectifs du cours

  • ✅ Comprendre la relation entre deux tables via une clé étrangère
  • ✅ Écrire une requête INNER JOIN
  • ✅ Écrire une requête LEFT JOIN
  • ✅ Savoir choisir la bonne jointure selon le besoin

1. Les tables de départ

Prenons deux tables : etudiants et reservations, liées par la colonne etudiant_id. 

CREATE TABLE etudiants (
    id INT PRIMARY KEY,
    nom VARCHAR(50)
);

CREATE TABLE reservations (
    id INT PRIMARY KEY,
    etudiant_id INT,
    matiere VARCHAR(50),
    FOREIGN KEY (etudiant_id) REFERENCES etudiants(id)
);

INSERT INTO etudiants VALUES (1, 'Awa'), (2, 'Cheikh'), (3, 'Fatou');
INSERT INTO reservations VALUES
    (1, 1, 'Mathématiques'),
    (2, 1, 'Python'),
    (3, 2, 'Anglais');
-- Remarque : Fatou (id 3) n'a encore aucune réservation

2. INNER JOIN : uniquement les correspondances

L'INNER JOIN ne retourne que les lignes qui ont une correspondance dans les deux tables. 

SELECT etudiants.nom, reservations.matiere
FROM etudiants
INNER JOIN reservations ON etudiants.id = reservations.etudiant_id;
nom matiere
AwaMathématiques
AwaPython
CheikhAnglais

Fatou n'apparaît pas, car elle n'a aucune réservation.

3. LEFT JOIN : toutes les lignes de la table de gauche

Le LEFT JOIN retourne toutes les lignes de la table de gauche (etudiants), même sans correspondance dans la table de droite. Les colonnes manquantes sont remplies avec NULL. 

SELECT etudiants.nom, reservations.matiere
FROM etudiants
LEFT JOIN reservations ON etudiants.id = reservations.etudiant_id;
nom matiere
AwaMathématiques
AwaPython
CheikhAnglais
FatouNULL

Quand utiliser quoi ? Utilisez INNER JOIN quand vous ne voulez que les données réellement liées entre les deux tables. Utilisez LEFT JOIN quand vous voulez conserver tous les enregistrements d'une table de référence, même sans correspondance (par exemple, lister tous les étudiants, y compris ceux qui n'ont encore rien réservé).

📝 Exercice d'application

En utilisant les tables etudiants et reservations ci-dessus, écrivez une requête permettant de lister le nombre de réservations par étudiant, y compris ceux qui en ont zéro.

Voir une solution possible 
SELECT etudiants.nom, COUNT(reservations.id) AS nb_reservations
FROM etudiants
LEFT JOIN reservations ON etudiants.id = reservations.etudiant_id
GROUP BY etudiants.nom;

-- Awa : 2, Cheikh : 1, Fatou : 0
