🌐 Créer une page web responsive

Exemple de cours donné par un tuteur EduSen en Développement Web

🎯 Objectifs du cours

  • ✅ Structurer une page avec HTML sémantique
  • ✅ Mettre en page avec Flexbox en CSS
  • ✅ Rendre un menu interactif avec JavaScript
  • ✅ Adapter l'affichage aux petits écrans (responsive)

1. La structure HTML

On commence par une structure sémantique claire, avec des balises qui décrivent le rôle de chaque section : 

<header>
  <nav class="navbar">
    <div class="logo">EduSen</div>
    <button id="menu-toggle">☰</button>
    <ul class="nav-links">
      <li><a href="#accueil">Accueil</a></li>
      <li><a href="#cours">Cours</a></li>
      <li><a href="#contact">Contact</a></li>
    </ul>
  </nav>
</header>

2. La mise en page avec Flexbox

Flexbox permet d'aligner et de répartir facilement les éléments d'une barre de navigation : 

.navbar {
  display: flex;
  justify-content: space-between;
  align-items: center;
  padding: 1rem 2rem;
}

.nav-links {
  display: flex;
  gap: 1.5rem;
  list-style: none;
}

/* Version mobile : le menu devient vertical sous 768px */
@media (max-width: 768px) {
  .nav-links {
    flex-direction: column;
    display: none;
  }
  .nav-links.active {
    display: flex;
  }
}

3. L'interactivité avec JavaScript

Un peu de JavaScript permet d'ouvrir et fermer le menu sur mobile au clic sur le bouton ☰ : 

const toggle = document.getElementById('menu-toggle');
const links = document.querySelector('.nav-links');

toggle.addEventListener('click', () => {
  links.classList.toggle('active');
});

Principe clé du responsive design : on conçoit d'abord pour mobile (mobile first), puis on ajoute des règles CSS via des @media queries pour adapter la mise en page aux écrans plus larges.
