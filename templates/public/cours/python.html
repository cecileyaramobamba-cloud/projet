🐍 Listes, tuples et dictionnaires

Exemple de cours donné par un tuteur EduSen en Python

🎯 Objectifs du cours

  • ✅ Manipuler des listes (ajout, suppression, tri)
  • ✅ Comprendre l'immutabilité des tuples
  • ✅ Utiliser des dictionnaires clé-valeur
  • ✅ Combiner ces structures dans un mini-programme

1. Les listes

Une liste est une collection ordonnée et modifiable d'éléments. 

matieres = ["Mathématiques", "Python", "Anglais"]

matieres.append("MySQL")          # ajoute un élément à la fin
matieres.remove("Anglais")        # retire un élément précis
matieres.sort()                   # trie la liste par ordre alphabétique

print(matieres)
# ['MySQL', 'Mathématiques', 'Python']

2. Les tuples

Un tuple ressemble à une liste, mais il est immuable : une fois créé, il ne peut plus être modifié. On l'utilise pour des données qui ne doivent pas changer (coordonnées, jours de la semaine…). 

coordonnees = (14.6928, -17.4467)  # latitude, longitude de Dakar

# coordonnees[0] = 15.0   -> provoquerait une erreur TypeError
print(coordonnees[0])  # 14.6928

3. Les dictionnaires

Un dictionnaire associe des clés uniques à des valeurs, ce qui permet un accès rapide par nom plutôt que par position. 

etudiant = {
    "nom": "Awa Ndiaye",
    "niveau": "Licence 3",
    "matieres": ["Python", "Mathématiques"]
}

print(etudiant["nom"])            # Awa Ndiaye
etudiant["age"] = 21               # ajoute une nouvelle clé
print(etudiant.get("ville", "Non renseignée"))  # Non renseignée

4. Mini-programme combinant les trois structures

etudiants = [
    {"nom": "Awa", "notes": (15, 12, 18)},
    {"nom": "Cheikh", "notes": (10, 14, 16)},
]

for etudiant in etudiants:
    moyenne = sum(etudiant["notes"]) / len(etudiant["notes"])
    print(f"{etudiant['nom']} : moyenne = {moyenne:.2f}")

# Awa : moyenne = 15.00
# Cheikh : moyenne = 13.33
